## What this is

A native Amiga port of **Europa Universalis II** (Paradox, 2001; GOG release **v1.09**,
`setup_europa_universalis2_2.0.0.1.exe`, MD5 `eb19eab80b45105d571bf684e18118a4`).
There is no source code: the engine is **our own reimplementation in C**. Data and scripts come from
the game files; rules (economy, combat, diplomacy, AI) are read out of `eu2.exe` in Ghidra **as a
specification only — decompiled code never goes into the repository**.

The port only runs on data the player extracts from **their own purchased GOG copy** with `eu2conv`.
It must be a net benefit for the authors, never a replacement: **no Paradox file, and nothing derived
from one, is ever committed or shipped.** `.gitignore` excludes the installer and the installed game
in the repo root; the release must gain a gate that refuses any original asset (OpenTTD's
`assert_no_original_ttd_data` is the model).

## Targets (user decisions 2026-11-08)

- Playable floor **68040/68060**, AGA **and** RTG. Reference test machine: **68020, no FPU, JIT off,
  CPU max speed with throttle -70 %** (≈ 060/50-60 MHz) — `winuae/eu2-ref020.uae`. The original
  wanted a 200 MHz Pentium, so the maths must be simplified (fixed point, no FPU) and the simulation
  optimised wherever possible.
- AGA: **640x480** (AGA overscan tops out at 724x566, 800x600 does not fit). The UI is rescaled with
  Lanczos at conversion time, plus a CC0 font that fits; the map can keep its original pixels (3 zoom
  levels). RTG: also the original UI at 800x600+.
- **AROS 68k and MorphOS from day one**, one 68k binary, run-time detection only:
  `FindResident("MorphOS")`, RTG deep (`WriteLUTPixelArray`), AHI on MorphOS, `adopt_screen_planes`
  (AROS ignores `SA_BitMap`), own `readdir` on `Lock/ExNext` (libnix readdir returns nothing on
  MorphOS), no hardware banging, char-signedness-clean code (a native PPC build comes later).

## Rules inherited from all our ports

Read `I:\GITHUB\!instrukcje_kompilacji_68K_AROS_i_MorphOS\README.md` and `10-68k-2D.md` before
writing Amiga code. The short list: bebbo gcc 6.5.0b in WSL, `-mcpu=68020 -msoft-float`, plain C,
never `-m68040`/`-lc`/`-lpthread`, never strip, never `sprintf` (use `snprintf`), no floats (fixed
point; locale.library puts a decimal comma into printf, so parse/print numbers ourselves — EU2's
text files are full of decimals), Amiga headers only in C platform files, `Stack 2000000`,
`PROGDIR:` only, own log with fflush, `-fbbb` without letters `i` and `e`, check the libm881 link
trace. A result that is impossible with good inputs is the compiler — build the same code on the host
and compare.

## Building and running

WSL commands are written to a script file and run through the mount wrapper (PowerShell and Git Bash
both mangle inline quoting): `wsl sh /mnt/c/temp/amiga_eu2/w.sh <script.sh>` — it remounts `I:`
(drops out of WSL1 regularly), puts `/opt/amiga/bin` on PATH and cds to the repo.

- Converter: `sh build/build-eu2conv.sh` → `build/host/eu2conv`, `eu2conv.exe`.
  `eu2conv <setup.exe> <outdir>` or `eu2conv --dir <installed folder> <outdir>`. Full run 24 s.
  Development copy of the converted data: `/home/angree/eu2out` (WSL), raw innoextract reference
  tree `/home/angree/eu2x/app` (for Ghidra / format work; never into the repo).
- git: use Windows git (WSL git cannot set core.filemode on this share).

## WinUAE

Runtime on the SSD in `C:\temp\amiga_eu2\` (a hardfile on `I:` hangs WinUAE): `uae\winuae-eu2.exe`
(own copy of 2.8.1), `boot.hdf` = WoW's `boot060.hdf` (has `68060.library`/`680x0.library`, saves the
40-minute install; mounted **ro**), `ROM3.1_A4000.40.70.ROM` (Amiga Forever, the user's), `work\` =
`Work:`. The HDF's User-Startup runs `Execute Work:run` (must have LF endings).
Hard rules: launch as `-f <abs cfg>` with `use_gui=no`; never kill WinUAE by name or with `-Force`
(other agents and the user run other guests) — only our PID / our config name; never synthesise host
input (drive the game from inside the guest: `Work:autoinput.txt`); never run tests in a guest the
user plays in; `gfx_api=1` for screenshots; quote speed only from the reference config.
